# Wren AI MCP plugins

Plugins that connect AI agents to [Wren AI](https://getwren.ai) over its
remote MCP server. Every host shares one analyst skill and signs in with
OAuth; there is no API key to configure.

| Host | Directory | Status |
|---|---|---|
| Google Antigravity | [`hosts/antigravity`](hosts/antigravity) | In review prep |
| Claude | `hosts/claude` | Planned |
| ChatGPT | `hosts/chatgpt` | Planned |

## Layout

```
skills/<name>/SKILL.md.tmpl   shared skill body with {{PLACEHOLDER}}s
fragments/<host>/             per-host values: simple.vars, <PLACEHOLDER>.md
hosts/<host>/                 what each host installs, committed as is
  skills/<name>/SKILL.md      generated by ./setup, do not edit by hand
  LICENSE                     copy of the root LICENSE
setup                         generates hosts/<host>/skills/
```

Manifests and MCP config are written by hand in each `hosts/<host>/`, since
no two hosts share a format. Only the skill is templated.

## Development

Edit the template or a fragment, then regenerate and commit the output.
Marketplaces install straight from git, so the generated files must be in the
repo. CI fails if they are stale.

```bash
./setup                  # all hosts
./setup --host antigravity
./setup --check          # what CI runs
```

Try the Antigravity plugin from a checkout:

```bash
agy plugin validate --strict hosts/antigravity
agy plugin install ./hosts/antigravity
```
